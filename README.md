Ce projet vise à **produire des statistiques sur l'usage des images dans ISTEX**. Il extrait les URLs d'images référencées dans les fichiers TEI du corpus, les charge dans une base DuckDB, puis calcule des indicateurs par document et à l'échelle du corpus :

- la part des documents qui référencent au moins une image ;
- le nombre d'images par document (moyenne, minimum, maximum) ;
- la part des doublons, avec le nombre d'images distinctes ;
- le nombre de balises `<graphic>` sans URL exploitable.

Les données brutes sont conservées sans filtrage, afin que les références vides soient décomptées.

## Prérequis

* duckdb
* xmlstarlet
* gzip
* make
* bash

## Utilisation

```bash
make CORPUS_DIR=/chemin/vers/corpus
```

| Cible            | Action                                              |
| ---------------- | --------------------------------------------------- |
| `make`           | Pipeline complet (`analyse`, `create_db`, `export`) |
| `make analyse`   | Extrait les URLs d'images vers le TSV compressé     |
| `make create_db` | Crée la base DuckDB à partir du TSV                 |
| `make export`    | Exporte `document_image_analysis` en CSV            |
| `make clean`     | Supprime les fichiers générés                       |
| `make help`      | Affiche l'aide et la configuration courante         |

### Variables de configuration

| Variable       | Défaut                   | Description                                                                           |
| -------------- | ------------------------ | ------------------------------------------------------------------------------------- |
| `CORPUS_DIR`   | `/path/to/corpus`        | Racine du corpus à analyser (peut être configurer pour correspondre à $CORPUS_OUTPUT) |
| `TSV_GZ_FILE`  | `/tmp/images_tei.tsv.gz` | TSV compressé produit par l'extraction                                                |
| `DB_SCRIPT`    | `sql/init.sql`           | Script SQL d'initialisation                                                           |
| `OUTPUT_DB`    | `tei_images.db`          | Base DuckDB générée                                                                   |
| `ANALYSIS_CSV` | `analysis_results.csv`   | Export CSV des résultats                                                              |

## Extraction

Le script ne traite que les fichiers `*/fulltext/*.tei.xml` situés à 6 niveaux de profondeur, par exemple : `<CORPUS_DIR>/0/3/1/0318E2018A6567011B9A60C9455B73BE8397E8D6/fulltext/xxx.tei.xml`

Pour chaque balise `//tei:graphic` (espace de noms `http://www.tei-c.org/ns/1.0`), il écrit une ligne `chemin<TAB>@url`. Un `<graphic>` sans attribut `url` produit une URL vide.

## Modèle de données

### `tei_image_references` (table brute)

| **Colonne**     | **Description**                                                                                               |
| --------------- | ------------------------------------------------------------------------------------------------------------- |
| `document_path` | Chemin ou identifiant du document source (ex. chemin du fichier TEI).                                         |
| `image_url`     | URL de l'image telle que lue dans le TSV, sans aucun nettoyage. Peut être NULL, vide ou contenir des espaces. |

### `tei_image_references_clean` (vue)

| **Colonne**     | **Description**                                                                                                                                            |
| --------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `document_path` | Identique à la table source.                                                                                                                               |
| `image_url_raw` | Valeur brute de `image_url`, identique à la table source.                                                                                                  |
| `image_url`     | Valeur nettoyée : espaces de début et de fin supprimés (y compris `\r` et tabulations). NULL si la valeur est NULL, vide ou composée uniquement de blancs. |

### `document_image_analysis` (vue, une ligne par document)

| **Colonne**             | **Description**                                                                                                             |
| ----------------------- | --------------------------------------------------------------------------------------------------------------------------- |
| `document_path`         | Chemin ou identifiant du document.                                                                                          |
| `total_reference_count` | Nombre total de références (lignes) pour ce document, vides comprises.                                                      |
| `image_count`           | Nombre de références avec une URL **non vide**, doublons inclus.                                                            |
| `empty_image_count`     | Nombre de références avec une URL NULL ou vide (`total_reference_count - image_count`).                                     |
| `unique_image_count`    | Nombre d'URLs **distinctes et non vides**. Vaut 0 si toutes les références du document sont vides.                          |
| `avg_images_per_doc`    | Moyenne globale de `image_count` sur **tous** les documents, y compris ceux à 0 image valide. Même valeur sur chaque ligne. |
| `max_images_per_doc`    | Maximum global de `image_count` sur un document. Même valeur sur chaque ligne.                                              |
| `min_images_per_doc`    | Minimum global de `image_count` sur un document. Peut valoir 0. Même valeur sur chaque ligne.                               |

### `global_image_stats` (vue, une seule ligne)

| **Colonne**             | **Description**                                                                                    |
| ----------------------- | -------------------------------------------------------------------------------------------------- |
| `documents_total`       | Nombre de `document_path` distincts, que leurs images soient vides ou non.                         |
| `documents_with_images` | Nombre de documents ayant au moins une URL non vide.                                               |
| `total_reference_rows`  | Nombre total de références (lignes) dans `tei_image_references_clean`.                             |
| `total_image_calls`     | Nombre total de références avec une URL non vide, doublons inclus.                                 |
| `empty_image_rows`      | Nombre total de références avec une URL NULL ou vide (`total_reference_rows - total_image_calls`). |
| `unique_images`         | Nombre d'URLs distinctes et non vides dans toute la base.                                          |
### `images_extensions` (vue, une ligne par extension)

| **Colonne**             | **Description**                                                                                    |
| ----------------------- | -------------------------------------------------------------------------------------------------- |
| `extension`       | extensions des images (top 10) |
| `nb` | Nombre d'images.                                               |
